# MO Habit Tracker & Task Manager 🎯
> **نظام متكامل لإدارة المهام وتتبع العادات اليومية والشهرية بالاعتماد على نموذج عجلة الانضباط الشعاعية (Discipline Tracker).**

---

## 📌 نبذة عن المشروع
تم تصميم وتطوير هذا النظام استناداً إلى نموذج لوحة الانضباط الورقية المرفقة، وتحويلها إلى تطبيق ويب تفاعلي واحترافي بنسبة 100% باستخدام **Laravel**، مع التركيز على:
1. **دائرة تتبع العادات التفاعلية (SVG Radial Wheel):** رسم شعاعي ديناميكي للحلقات والأيام يحاكي بدقة ورقة التتبع الأصلية، مع تلوين فوري للقطاعات (التركوازي للمنجز، والبرتقالي للأعذار/غير المنجز).
2. **NOTE & REFLECTIONS:** دفتر تأملات يومية بتصميم الورقة المسطرة لتسجيل الإنجازات وما تعلمته اليوم وتقييم الانضباط.
3. **Excuses I Overcome:** قسم مخصص لتسجيل أسباب عدم الالتزام (ضيق الوقت، التعب، التشتت، انعدام الرغبة) وتحليلها ووضع خطط عملية لتجاوزها.
4. **نظام مهام احترافي متكامل:** إدارة شاملة للمهام مع الأولويات، التصنيفات، التكرار، والتواريخ، وحساب نسبة الإنجاز فورياً.
5. **لوحة تحكم وتقارير متقدمة:** رسوم بيانية وتتبع لسلاسل الالتزام (Streak) مع دعم كامل للغتين العربية (RTL) والإنجليزية (LTR)، والوضع الليلي/النهاري.

## 🛠️ خطوات التشغيل على Windows باستخدام XAMPP

### الخطوة 1: تشغيل خدمة MySQL في XAMPP
افتح برنامج **XAMPP Control Panel** واضغط على زر **Start** بجانب **MySQL** (أو من خلال سطر الأوامر).

### الخطوة 2: الدخول إلى مجلد المشروع
افتح موجه الأوامر (PowerShell أو CMD) وانتقل إلى مسار المشروع:
```powershell
cd C:\xampp\htdocs\task
```

### الخطوة 3: تجهيز قاعدة البيانات والتنصيب الأولي (تم تنفيذها مسبقاً)
إذا كنت بحاجة لإعادة بناء الجداول وبث البيانات التجريبية من جديد في أي وقت:
```powershell
php artisan migrate:fresh --seed
```

### الخطوة 4: تشغيل خادم التطوير
يمكنك تشغيل المشروع بإحدى طريقتين:

#### الطريقة الأولى (الموصى بها): عبر خادم Laravel المدمج
```powershell
php artisan serve
```
ثم افتح متصفحك وتوجه إلى:
👉 **[http://127.0.0.1:8000](http://127.0.0.1:8000)**

#### الطريقة الثانية: عبر أباتشي XAMPP مباشرة
إذا كان أباتشي يعمل في XAMPP، توجه مباشرة في متصفحك إلى:
👉 **[http://localhost/task/public](http://localhost/task/public)**

## 📋 أقسام وصفحات الموقع

### 1. لوحة التحكم (Dashboard)
- بطاقات المؤشرات الرئيسية: نسبة إنجاز اليوم، نسبة إنجاز الشهر، أطول سلسلة التزام (Streak)، والمهام المتبقية.
- دائرة تتبع العادات التفاعلية في المنتصف مع إحصاءات الإنجاز.
- قائمة العادات السريعة لليوم (تسجيل بضغطة زر واحدة).
- رسم بياني لأداء آخر 7 أيام.
- قائمة المهام اليومية مع إمكانية إنجازها فورياً.

### 2. دائرة العادات (Habits Tracker) — الصفحة الرئيسية للنظام
- **العجلة الشعاعية التفاعلية (SVG Radial Wheel):**
  - تدعم أي عدد من العادات (كل عادة تمثل حلقة دائرية متحدة المركز).
  - تدعم الحساب الدقيق لعدد أيام أي شهر (28، 29، 30، 31 يوماً مع حساب السنة الكبيسة وشهر فبراير).
  - عند الضغط على أي خلية، تظهر قائمة منبثقة فورية لحفظ الحالة: (تم الإنجاز ✓ باللون التركوازي، لم يتم باللون البرتقالي مع كتابة السبب، تخطي اليوم، أو إلغاء التحديد).
  - حفظ فوري بتقنية AJAX في قاعدة البيانات مع تحديث الإحصائيات ونسب الالتزام.
  - إمكانية إضافة عادة جديدة، تعديل لونها واسمها، وتحديد عدد أيام الهدف الأسبوعي.
- **قسم NOTE & REFLECTIONS:** دفتر ملاحظات بالورقة المسطرة لكتابة تأملات اليوم، إنجاز اليوم الأكبر، والدروس المستفادة.
- **قسم Excuses I Overcome:** قائمة بالأعذار التي واجهتها وكيفية التغلب عليها مع علامة إنجاز عند قهر كل عذر.

### 3. إدارة المهام والمهام الفرعية (Tasks & Subtasks)
- إضافة مهمة جديدة بتفاصيلها: الأولوية (عالية، متوسطة، منخفضة)، التاريخ، الوقت، التصنيف، والتكرار (يومي، أسبوعي، شهري).
- **المهام الفرعية (Subtasks):** إمكانية إضافة وتعديل وحذف مهام فرعية تحت كل مهمة رئيسية مع شريط تقدم ونسبة إنجاز لحظية (مثل: 3 من 5 مكتملة — 60%).
- مزامنة ذكية: اكتمال المهمة الرئيسية تلقائياً عند اكتمال جميع مهامها الفرعية، وتأكيد عند محاولة إكمال المهمة الرئيسية في حال وجود مهام فرعية غير منجزة.
- وضع علامة صح عند الإنجاز يتغير شكلها وتُحفظ لحظياً مع تاريخ ووقت الإنجاز الدقيق.
- فلاتر متطورة: البحث بالنص، التصفية حسب الأولوية، التصنيف، الحالة (قيد الانتظار / مكتملة)، أو التاريخ (اليوم، هذا الأسبوع، المتأخرة).

### 4. المساعد الذكي الشخصي (MO AI Assistant) 🤖
مساعد ذكاء اصطناعي متكامل مرتبط مباشرة ببيانات المهام والعادات الخاصة بالمستخدم في قاعدة البيانات لمساعدته على اتخاذ القرارات والتركيز:
- **وضع «أنا مشتت، ساعدني!»:** يراجع المهام غير المكتملة ويختار مهمة واحدة فقط للبدء بها مع تحديد خطوة أولى لمدة 20 دقيقة وزر «ابدأ المهمة».
- **وضع «رتّب يومي»:** ينشئ خطة يومية واقعية ومتوازنة مبنية على الأولويات والعادات والمهام المتأخرة دون إرهاق.
- **وضع «قسّم مهمة»:** يحلل أي مهمة كبيرة ويقترح 4 إلى 6 مهام فرعية مرتبة مع زر «إضافة إلى مهامي» لحفظها بعد الموافقة.
- **البحث في Google والويب:** إمكانية البحث الفعلي على الإنترنت واسترجاع مصادر وروابط موثوقة مع تمييز واضح بين بيانات الموقع ومصادر الويب الخارجية.
- **تكامل الذكاء الاصطناعي:** يدعم Google Gemini API (`gemini-1.5-flash`) ونماذج OpenAI / Groq، مع محرك محلي ذكي يعمل حتى بدون مفاتيح API.

### 5. الملاحظات والتأملات (Reflections)
- دفتر تأملات يومي كامل.
- تسجيل أفضل إنجاز حققته اليوم.
- ما تعلمته اليوم (Lessons Learned).
- تقييم الانضباط اليومي من 1 إلى 5 نجوم.
- ما ترغب في تحسينه غداً.
- سجل أرشيفي كامل لاستعراض تأملات الأيام والشهور السابقة.

### 6. أسباب عدم الإنجاز (Excuses I Overcome)
- تحليل أسباب التراجع: ضيق الوقت، التعب والإرهاق، التشتت بالسوشيال ميديا، عدم الشعور بالرغبة، أو سبب مخصص.
- خطة عملية للتغلب على كل عذر مستقبلاً.
- متابعة نسبة الانتصار على الأعذار وتطوير الانضباط الذاتي.

### 7. التقارير والإحصائيات (Analytics)
- رسوم بيانية تفاعلية عبر Chart.js:
  - تطور نسبة الالتزام على مدار آخر 6 أشهر.
  - توزيع المهام حسب التصنيفات.
- جدول تفصيلي لأداء كل عادة مرتبة حسب الأعلى التزاماً، وسلسلة الأيام المتتالية، وتصنيف الأداء (ممتاز، جيد، يحتاج تركيز).

### 8. الإعدادات والتفضيلات (Settings)
- تبديل المظهر بنقرة واحدة: الوضع النهاري (Light) والوضع الليلي (Dark).
- تبديل اللغة: العربية (RTL) والإنجليزية (LTR).
- تخصيص ألوان الهوية وتصنيفات المهام.
- إدارة الملف الشخصي وكلمة المرور.

## 🤖 إعداد المساعد الذكي (AI Setup)
المساعد الذكي يعمل فوراً بدون أي إعداد إضافي باستخدام المحرك الذكي المحلي والبحث الحي على الويب.  
لتفعيل الذكاء الاصطناعي التوليدي الكامل عبر **Google Gemini** أو **OpenAI**، أضف المفاتيح في ملف `.env`:

```env
# Google Gemini API (مجاني وسريع ويدعم اللهجات العربية)
GEMINI_API_KEY=your_gemini_api_key_here
GEMINI_MODEL=gemini-1.5-flash

# اختياري: OpenAI / Groq
OPENAI_API_KEY=
OPENAI_MODEL=gpt-4o-mini

# اختياري: محرك بحث Google المخصص
GOOGLE_SEARCH_API_KEY=
GOOGLE_SEARCH_CX=
```
